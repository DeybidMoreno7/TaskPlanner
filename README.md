# TASK PLANNER
¿A quién no se le ha olvidado alguna tarea en su vida? Quizá haya sido un trabajo académico o simplemente sacar la basura. 
El resultado es el mismo, ese escalofrío por todo el cuerpo cuando recuerdas "debía hacer esto", "debía hacer aquello".
Pues bien, el presente Task Planner surge con el propósito de alivianar la carga para aquellas personas que suelen olvidar 
muy fácilmente las cosas. Basta con llenar un formulario para que la interfaz intuitiva de la aplicación te guie y puedas 
gestionar completamente el estado de tus tareas/asignaciones/pendientes. Podrás monitorear sus estados en las columnas 
"To Do" - "In progress" - "Done" y el calendario te ayudará a tener una perspectiva visual de tu mes o semana.
Anímate a probarlo :D.
